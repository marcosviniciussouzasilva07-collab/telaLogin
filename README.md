## 💻 Sobre o Projeto
Este projeto consiste em um fluxo completo de frontend para autenticação de usuários. Ele apresenta uma **Tela de Login** tradicional e uma **Tela de Registro** para novos usuários, integradas através de um menu de seleção dinâmico (dropdown) usando JavaScript nativo.

🔗 **[Clique aqui para acessar o projeto online via GitHub Pages](https://marcosviniciussouzasilva07-collab.github.io/telaLogin)**

## ✨ Funcionalidades
*   **Acesso Rápido:** Formulário de login intuitivo (`index.html`).
*   **Criação de Conta:** Página de registro dedicada com validação visual de campos (`novouser.html`).
*   **Roteamento Dinâmico:** Navegação fluida entre telas utilizando o evento `onchange` do JavaScript em um menu `<select>`, sem necessidade de frameworks pesados.
*   **Design Responsivo:** Layout adaptável criado com CSS moderno para funcionar perfeitamente em dispositivos móveis e desktops.

## 🛠️ Tecnologias Utilizadas
As seguintes ferramentas foram usadas na construção do projeto:
*   **HTML5:** Estruturação semântica.
*   **CSS3:** Estilização, layout (Flexbox/Grid) e responsividade (`style.css`).
*   **JavaScript (Vanilla):** Lógica de redirecionamento.
